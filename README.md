# Topi Autio - Hugo Experiment

This branch is for testing Hugo static site generator.

## Quick Start (local)

1. `git clone -b hugo-experiment https://github.com/topiautio/topiautio-kotisivu.git`
2. `cd topiautio-kotisivu`
3. `git submodule add https://github.com/gurusabarish/hugo-profile.git themes/hugo-profile`
4. `hugo server` — open http://localhost:1313

Deploy with GitHub Pages / Netlify after building with `hugo`.

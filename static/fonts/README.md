# Self-hosted fonts

The site bundles the following fonts locally so page rendering does not require a request to a third-party font service:

- DM Sans, variable weights 300–600
- DM Serif Display, regular
- DM Mono, regular and medium

The font files are downloaded from the Google Fonts distribution of the
[DM Sans](https://github.com/googlefonts/dm-fonts),
[DM Mono](https://github.com/googlefonts/dm-mono), and
[DM Serif Display](https://github.com/google/fonts) projects. They are
distributed under the SIL Open Font License 1.1; the corresponding license
texts are stored next to the files.
